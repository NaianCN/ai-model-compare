怎么算的、要注意什么

  • 能从官方数字算出来的有六家：GLM、MiMo、DeepSeek 按量付费，以及 Command Code、OpenCode 的 DeepSeek 额度。公式是"额度或预算 ÷ 统一负载下每 token 的消耗"，结果和 real-api-pricing 一致。Claude、ChatGPT 不公布 token 额度，数字来自账号实测，实测又受缓存率和模型影响。Plus 只有每 token 的 credits 费率，没有公布 Plus 含多少 credits，所以没做积分估算。
  • 总量对缓存率非常敏感。Wokey 观测的 Claude Pro 真实流量缓存读取只占 83%，每周约 1.41 亿 token，比 97% 负载下少很多。自己的缓存率低，实际可用量会明显低于图上的数字。
  • "等比折算"不是真实能买到的档位，只是把花费拉到同一水平：GLM ¥118 × 1.14，MiMo 和 Kimi ¥99 × 1.36，Qoder ¥59 × 2.28，Qoder ¥169 × 0.79，Kimi ¥199 × 0.67。实际买不到 ¥134 的档位。Qoder 可以用 ¥59 专业版加 ¥40 资源包，¥99 共 3000 Credits。
  • Qoder CN 的本页估算。官方没有 token 换算，只给了 50K 上下文下 Ask 约 3–4 Credits / 次。按一次 Ask 约等于一次 5 万 token 的调用，1 Credit ≈ 1.25–1.67 万 token（含缓存）。假设这个参考值对应默认的 Auto（0.5×），其他模型按官方系数缩放，而官方说系数不是抵扣依据。两个对照结果接近：¥59 按 Qwen3.8-Max 的 API 价（CreditsPlan 所列）买统一负载约 0.30 亿；CSDN 单人估算折算后 0.20–0.33 亿。CSDN 按一次任务（约 1.5 万输入、3000 输出，扣三四十 Credits）倒推，我把它当作不含缓存的 token，再按 3% 占比换成总量。
  • Kimi 的本页估算。官方只有额度倍数和模型消耗倍数，没有 token 额度。Pro 用 Wokey 测的每窗口 token 限额换算到统一负载，缓存读取按输入的 1/10 得 2.47 亿，按免费得 5.77 亿。Plus 取一半，没有计入 256K 版可能的折扣。codingplan.fyi 认为 Pro 的 Code 额度是 Plus 的 5 倍，若如此 Plus 还要再低。
  • 四个订阅套餐已按额度置信度重算。数据源是 realapipricing.com 2026-11-10 的数据，筛选条件为厂商 Anthropic / DeepSeek / OpenAI、渠道 Anthropic / OpenAI / Command Code / OpenCode、订阅计费、月费 $0–30。只收「高」「中」置信，同一模型有更高置信度时取更高，低置信全部剔除：Claude Pro 少了 3 条（Opus 4.8、Sonnet 5.5、Haiku 5.5，都是按倍率推算），ChatGPT Plus 去掉了本页旧的 GPT-6.1 Terra 17.4 亿推算值。两个 $10 套餐按「以 DeepSeek 为准」只收 DeepSeek 模型，另有 8 条 GPT / Claude 模型中置信额度没有列入。合计采用 20 条，其中高置信 7 条、中置信 13 条。每个标签都写明实测来源，非实测的以来源网站命名，末尾的「高 / 中」才是置信度。
  • GPT-6.1 Sol 从 8.70 亿改成 15.16 亿：维护者 11-09 周窗的两条标准负载读数等权中点，旧的 31pp / 8.70 亿与整周 67% 外推都不再入权。GPT-6 Astra 的 1.59 亿仍是实测原始负载，没换算到统一负载；GPT 5.6 Sol 6.16 亿也是没有分项、保留 raw 的样本。
  • 两个 $10 套餐的折算要看清。Command Code GOAT、OpenCode Go 都只卖 $10 一档，页面默认"等比折算到 $20"时按 ×2 放大，只是把花费拉齐，不代表真能一次买到 $20 的额度；切到"按实际档位价"看真实额度。两者的额度来自官方逐模型 allowance / Usage 表，置信度为「中」；DeepSeek V4.1 Flash 在 OpenCode Go 的 103.52 亿是 2026-10-30 上调后的值。
  • 额度会变。Wokey 记录 Plus 每周价值从 10-08 的 $92 降到 10-26 的 $55；本次采用的 GPT-6.1 Sol 15.16 亿来自 11-09 的新读数，比 09-30 的 8.70 亿还高，说明不同周窗差异很大。Claude Pro 的 Opus 5.5 由 09-22~09-27 的实测合并了 11-07 的满窗读数。
  • 明细表的 AA 智力来自 AI 模型花费与智力对比 的 AA 智力指数，取各模型最高思考档。本次新增的订阅额度行只在该页收录过的模型上填分数，其余显示「—」：realapipricing.com 用的是 AA v4.3，与本页 v5.x 口径不同，不混用。用低思考档时分数更低、消耗的 token 也更少，表里的用量没有按档位区分。
  • Wokey 卖按量 API，与订阅有利益关系；Kimi 数字中 Max 的基准只有一个账号。SemiAnalysis 正文付费，这里用的是公开部分和 explainx 的转述。
  • 置信度不是精度。「高」表示有账号面板或本机实测，「中」表示官方额度换算或由同套餐基准推算，「低」是按倍率外推；高置信的数字仍可能随周窗和缓存率大幅变化。realapipricing.com 的置信度只针对额度，不代表模型能力评价。
  • 价格都是连续包月原价，不含首购、包年折扣。GLM 老用户可按 ¥49 / ¥149 / ¥469 续订旧版，新用户买不到。GLM 的月费来自 codingplan.fyi、pingfan 等第三方（互相一致），未对照智谱购买页核实。
